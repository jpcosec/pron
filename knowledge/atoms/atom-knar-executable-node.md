# ExecutableNode es el contrato común de los componentes ejecutables

## Answer

ExecutableNode reúne identidad operacional, puertos, acceso a conocimiento, capacidades, máquina de estados, runtime, completion tests y ejecución. Todo elemento ejecutable expone ese contrato, aunque su implementación interna sea un LLM, una consulta, una API o una composición.
