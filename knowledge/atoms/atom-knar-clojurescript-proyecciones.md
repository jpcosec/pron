# La propuesta inicial usa ClojureScript para proyecciones de browser y UI

## Answer

El spec propone ClojureScript para las proyecciones destinadas al navegador y a la interfaz. El ejemplo ArticleKnowledge → ArticleViewModel ilustra una transformación de representación que puede implementarse en esa capa.
