# Projection es una representación particular del conocimiento

## Answer

Una Projection expresa el conocimiento bajo una representación adecuada para un consumidor o una finalidad. Puede servir como contexto de un nodo o como una vista del conocimiento; el proyector es el componente que realiza la transformación hacia esa representación.
