# El prompt se deriva de SelfDoc, conocimiento y contrato

## Answer

El prompt de un nodo LLM se obtiene como una proyección de su identidad operacional, conocimiento pertinente y contrato. La definición primaria del comportamiento permanece en esas estructuras semánticas, lo que permite adaptar su representación al backend.
