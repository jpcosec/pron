# Spec2viz should generate maintained diagrams from structured sources

## Answer

Spec2viz should generate maintained diagrams from structured sources. It should derive diagrams from explicit semantic specifications rather than rely on hand-maintained drawings that drift from the modeled system. That implies the maintained source of truth is the structured input, with diagrams as reproducible views.
