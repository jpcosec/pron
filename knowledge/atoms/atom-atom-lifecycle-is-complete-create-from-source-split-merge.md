# Atom lifecycle is complete: create-from-source, split, merge

## Answer

deskops atoms supports split (provenance-safe rerouting, inbound-ref guard), merge (reference reconciliation to target, provenance preserved), and create-from-source (--from-pill/--from-graph/--from-diagram with exact provenance back to the source surface); mutating operations block on ambiguity without --force.
