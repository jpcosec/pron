# WiGame as Local Language Game

## Answer

A WiGame is the local language game where propositions and facts are evaluated. It binds an LiSpace (axis_a, axis_b, relation_id), ViMatrix (truth), SiMatrix (sense), propositions, and facts. It exposes search (Vi constrained by Si), purity checks (no unsinnig), tautology detection, and serialization. WiGames are the operational leaf nodes of the context hierarchy.
