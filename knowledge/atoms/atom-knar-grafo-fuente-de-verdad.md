# El grafo tipado es la fuente de verdad semántica

## Answer

El grafo de conocimiento tipado define qué componentes existen, qué significan y cómo se relacionan en el sistema. Las definiciones de ejecución se obtienen de ese conocimiento; ni un prompt ni un workflow particular asumen esa autoridad.
