# Atom status tags should support review and migration governance

## Answer

Atom status tags should support review and migration governance because the corpus needs explicit signals for maturity, review state, and pending migration or provenance work. They are not merely topical labels; separating governance state from subject matter implies review queues, transitions, and exceptions can be queried directly.
