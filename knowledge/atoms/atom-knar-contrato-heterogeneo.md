# El contrato común permite componer mecanismos internos heterogéneos

## Answer

Un scraper, un LLM, PostgreSQL, una API, un generador Astro o un sistema multiagente pueden participar como piezas del mismo sistema porque exponen el contrato común. La interoperabilidad se sostiene en transformaciones y puertos, sin exigir uniformar sus mecanismos internos.
