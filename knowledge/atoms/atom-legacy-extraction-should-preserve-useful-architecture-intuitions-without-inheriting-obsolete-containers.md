# Legacy extraction should preserve useful architecture intuitions without inheriting obsolete containers

## Answer

Legacy extraction should preserve useful architecture intuitions without inheriting obsolete containers. It should carry forward proven ideas while distinguishing them from historical implementation boundaries that no longer fit the new KB. That implies migration can retain insight without recreating outdated structures.
