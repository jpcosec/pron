# Los completion tests definen cuándo se cumplió el objetivo del nodo

## Answer

Un completion test expresa una condición que debe comprobarse para considerar terminada correctamente una ejecución. Puede verificar resultados y efectos necesarios para la transformación prometida, en lugar de limitarse a que una función haya retornado.
