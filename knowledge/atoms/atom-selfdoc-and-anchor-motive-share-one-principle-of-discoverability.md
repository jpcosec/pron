# SelfDoc and anchor motive share one principle of discoverability

## Answer

KNAR's SelfDoc lets an orchestrator discover which node to use without reading its code; the anchor's motive lets a user or agent discover what a symbol means without reading the evaluator. Both apply the same principle: every executable thing carries a formal, queryable declaration of its responsibility, so discovery is a knowledge query rather than code inspection.
