# Anchored in should connect a sample to the locator bundle used to recover it

## Answer

The relation `anchored_in` should connect a sample to the anchor bundle or structural locator set used to recover it from the bound source artifact. It identifies the recovery mechanism rather than the claim being made, so later validation can test whether the sample is still recoverable from that source version.
