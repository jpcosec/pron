# JSON and YAML sources should expose object-path projections for anchoring

## Answer

JSON and YAML sources should expose object-path projections for anchoring. Samples should bind to structured fields and nested objects, not rely only on flattened text excerpts that lose location within the object graph. That implies anchors can be more precise, stable, and structurally meaningful.
