# Section paths symbol paths and AST paths are complementary anchor families

## Answer

Section paths, symbol paths, and AST paths should all be treated as valid anchor families. They differ by the structure a source exposes—documents organize by sections, code by symbols, and parsed artifacts by syntax trees. Treating them as complementary lets the KB anchor evidence deterministically across heterogeneous source types.
