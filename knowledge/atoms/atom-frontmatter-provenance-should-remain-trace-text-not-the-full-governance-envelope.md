# Frontmatter provenance should remain trace text, not the full governance envelope

## Answer

Frontmatter `provenance` should remain a compact trace statement that tells readers where the claim came from, but it should not absorb the atom’s full governance profile. Project context, grounding state, editorial role, phase, and similar management facets belong in the metadata registry so the atom body stays focused on the claim.
