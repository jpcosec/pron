# Governance tags should help detect malformed atoms not only retrieve them

## Answer

Governance tags should help detect malformed atoms, not just retrieve them. Unlike topical tags, they encode expectations about structure, provenance, and grounding that can be checked for omissions or contradictions. Using them diagnostically lets the KB surface quality failures early instead of merely labeling them after ingestion.
