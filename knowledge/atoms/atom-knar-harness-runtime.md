# DeepSeek Harness ocupa el lugar de un runtime de ejecución

## Answer

DeepSeek Harness se integra mediante un adapter que recibe una AgentSpec procedente del sistema de conocimiento. Su función es ejecutar esa definición; la arquitectura principal y la semántica del agente siguen perteneciendo al Knowledge System.
