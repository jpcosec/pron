# Composes should link atoms into larger synthesized knowledge artifacts

## Answer

The relation `composes` should link atoms into reports, syntheses, and other higher-level knowledge artifacts so larger outputs can be assembled from stable atomic claims. It does not collapse many atoms into one oversized record; preserving modular parts implies syntheses can be regenerated, revised, and compared without rewriting the underlying atoms.
