# CompositeNode expone una composición mediante un contrato externo

## Answer

Un CompositeNode contiene varios nodos internamente y presenta externamente una entrada y una salida tipadas. Esta encapsulación permite usar un workflow o una aplicación completa como pieza de otra composición.
