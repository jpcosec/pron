# Promotion flattens structured source sections into task fields

## Answer

Inbox-to-drawer and drawer-to-active promotion flatten structured source sections (Goal, Scope, Validation, Implementation Path, Done When) into their target task fields so active-task section extraction never loses fields to nested headings.
