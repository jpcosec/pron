# KnowledgeProjection delimita el conocimiento disponible para una tarea

## Answer

Una proyección selecciona la parte del grafo pertinente para un nodo o una representación. Su declaración puede indicar raíces, tipos de relaciones, profundidad y permisos; distintos consumidores pueden recibir proyecciones diferentes del mismo conocimiento.
