# ASG projects multiple graphs per document

## Answer

From the same marked prose, the ASG derives a struct tree (structural containment), sem taxonomy (conceptual classification, crossing allowed), rhet graph (discourse roles, addressable nodes required), proc flow (procedural dependencies), and other namespace-specific projections. Node types include document, block, marker, span, and classification. Edge types include contains, covers_span, classified_as, parent_of, justifies, supports, elaborates, contrasts, depends_on, and summarizes.
