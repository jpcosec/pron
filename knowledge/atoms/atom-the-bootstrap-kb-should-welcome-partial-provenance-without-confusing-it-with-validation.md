# The bootstrap KB should welcome partial provenance without confusing it with validation

## Answer

The bootstrap KB should welcome partial provenance as a legitimate intermediate state so ingestion can begin before every source trail is complete. Partial provenance is not the same as validation, and keeping that boundary explicit implies the corpus can grow quickly without overstating evidentiary confidence.
