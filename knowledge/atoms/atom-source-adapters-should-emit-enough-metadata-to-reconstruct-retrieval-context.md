# Source adapters should emit enough metadata to reconstruct retrieval context

## Answer

Source adapters should emit enough metadata to reconstruct retrieval context because later validation depends on where content came from and how the adapter produced it. That metadata is not incidental decoration around the payload; it implies the KB can re-find, re-parse, and audit a claim when questions arise.
