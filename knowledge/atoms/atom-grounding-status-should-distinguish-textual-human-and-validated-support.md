# Grounding status should distinguish textual, human-located, and validated support

## Answer

Grounding status should distinguish at least textual-only support, human-located support, sample-linked support, and validated support so the KB can measure evidential maturity without collapsing all provenance into a binary present-or-absent state. This makes migration planning and trust assessment much more precise.
