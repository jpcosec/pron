# Cross-project synthesis atoms should be reviewable independently from local source atoms

## Answer

Cross-project synthesis atoms should be reviewable independently from local source atoms. They add interpretive or architectural value across several corpora, which is different from merely restating a local source-bound claim. That implies they need their own review surface and governance trail.
