# The ontology loop should iterate by mapping relations before freezing entity taxonomies

## Answer

The ontology loop should iterate by mapping relations before freezing entity taxonomies because relations reveal which distinctions actually matter in practice and which new entity types need to exist to support those distinctions coherently.
