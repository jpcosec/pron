# Runtime es el backend que materializa una transformación

## Answer

Un runtime proporciona el mecanismo de ejecución de un nodo. El spec contempla backends LLM, SQL, HTTP, Shell, Clojure, JavaScript, WASM, Astro, DeepSeek Harness y humanos, sin exigir que todos funcionen internamente de la misma manera.
