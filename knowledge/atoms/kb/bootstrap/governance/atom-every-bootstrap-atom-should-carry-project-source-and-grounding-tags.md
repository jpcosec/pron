# Every bootstrap atom should carry project, source, and grounding tags

## Answer

Every atom created in the bootstrap KB should carry at least `project:*`, `source:*`, `source_kind:*`, and `grounding:*` tags so the corpus can be governed by origin, source type, and provenance maturity from the beginning. This prevents the atom set from becoming a flat collection of statements whose scope and evidential status are hard to audit later.
