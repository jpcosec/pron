# The bootstrap KB must preserve current atom ids and 5WH1+ discipline

## Answer

The bootstrap KB should not break the stable ids and one-question 5WH1+ discipline of the current Deskops atoms, because those properties already provide durable identity, composability, and retrieval value. Future enrichment should extend atoms with provenance and concept structure, not erase the constraints that make them reusable now.
