# AST is a first-class document structure category in the KB

## Answer

AST should be treated as a first-class document-structure category in the KB, not as a parser implementation detail. When a source has parseable structure, the system should be able to use AST projections directly for anchoring, navigation, support modeling, and structural graph projection.
