# New work should create sample-ready atoms even before full backfill

## Answer

New work should create atoms that are ready to receive explicit sample links even if the historical corpus has not yet been fully backfilled. This lets the KB improve provenance quality forward-first instead of blocking new knowledge creation on complete retrospective migration.
