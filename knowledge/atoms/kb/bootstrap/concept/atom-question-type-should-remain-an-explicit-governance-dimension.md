# Question type should remain an explicit governance dimension

## Answer

Question type should remain an explicit governance dimension because the one-question 5WH1+ form is part of what gives atoms their composability, boundedness, and retrieval behavior. Treating question type as first-class also helps detect malformed atoms that silently answer multiple kinds of questions at once.
