# Bootstrap provenance should begin with source stubs before full samples

## Answer

Bootstrap provenance should begin with source stubs that record named source surfaces, source type, and currently known location hints before the system requires fully modeled samples. This lets the KB track origin honestly now while preparing atoms for later enrichment with deterministic sample bindings.
