# The bootstrap KB should track grounding status explicitly

## Answer

The bootstrap KB should track grounding status explicitly so the corpus can distinguish useful atoms with weak textual provenance from atoms that are sample-linked or fully validated. This avoids pretending that all atoms already have strong provenance while still letting the KB grow incrementally from the current Deskops corpus.
