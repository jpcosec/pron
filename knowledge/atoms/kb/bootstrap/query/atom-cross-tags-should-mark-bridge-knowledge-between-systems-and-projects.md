# Cross tags should mark bridge knowledge between systems and projects

## Answer

Cross tags should explicitly mark atoms that synthesize relations between systems, projects, or graph layers so those bridge statements remain queryable as first-class ecosystem knowledge. Without that marking, synthesis tends to disappear into local notes and becomes hard to recover systematically.
