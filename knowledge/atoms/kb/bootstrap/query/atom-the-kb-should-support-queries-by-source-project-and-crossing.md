# The KB should support queries by source, project, and crossing

## Answer

The bootstrap KB should support direct queries by source, project, and crossing because governance depends on being able to separate local knowledge, source-derived knowledge, and synthesized bridge knowledge. Those three retrieval axes are necessary to understand coverage, reuse, and provenance gaps across the corpus.
