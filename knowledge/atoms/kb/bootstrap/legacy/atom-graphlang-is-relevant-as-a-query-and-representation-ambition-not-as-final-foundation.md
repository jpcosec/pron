# Graphlang is relevant as a query and representation ambition, not as final foundation

## Answer

Graphlang remains relevant because it expresses the ambition to query and represent knowledge through graph-shaped structures, but it should be treated as an inspirational line rather than the final foundation of the new KB. The current architecture should reuse the ambition while grounding it in explicit sources, samples, atoms, and graph strata.
