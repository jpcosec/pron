# Deskops is a bootstrap surface, not the final KB container

## Answer

Deskops should be used as the current operational and authoring surface for the bootstrap KB, but it should not be treated as the final architectural container of the knowledge system. The KB must remain logically separable from `desk/` so future samples, concept graph structures, and multi-source support can evolve without being trapped inside the operational workspace.
