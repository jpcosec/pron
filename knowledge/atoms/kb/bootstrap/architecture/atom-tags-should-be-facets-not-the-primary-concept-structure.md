# Tags should be facets, not the primary concept structure

## Answer

Tags should remain as lightweight facets for grouping and retrieval, but they should not carry the full conceptual burden of atom placement, hierarchy, or conceptual relations. The deeper semantic structure should move into explicit concept, taxonomy, and relation nodes in the graph.
