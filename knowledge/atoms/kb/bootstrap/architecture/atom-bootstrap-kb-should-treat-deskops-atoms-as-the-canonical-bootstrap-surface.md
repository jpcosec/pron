# The bootstrap KB should treat current Deskops atoms as the canonical bootstrap surface

## Answer

The first KB build should use the current Deskops atom corpus as its canonical bootstrap knowledge surface, because those atoms already contain stable ids, 5WH1+ discipline, curated answers, and usable tags. They should be treated as valid knowledge units now, while the system remains explicitly open to future enrichment through samples, concept graph structure, and stronger provenance.
