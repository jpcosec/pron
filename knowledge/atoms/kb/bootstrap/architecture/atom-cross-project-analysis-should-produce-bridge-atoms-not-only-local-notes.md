# Cross-project analysis should produce bridge atoms, not only local notes

## Answer

Cross-project analysis should produce explicit bridge atoms that capture reusable relations between projects, tools, and historical architecture lines, instead of leaving those insights buried in local notes or one-off summaries. Bridge atoms make ecosystem-level synthesis queryable, composable, and governable inside the KB.
