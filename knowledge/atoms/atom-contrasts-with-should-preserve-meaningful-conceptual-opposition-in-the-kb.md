# Contrasts with should preserve meaningful conceptual opposition in the KB

## Answer

The relation `contrasts_with` should mark real conceptual opposition in the KB. It is not hierarchy, dependency, or mere topical relatedness; it names cases where meaning becomes clearer through difference. Preserving that edge type helps retrieval and explanation surface boundaries that would otherwise be flattened.
