# Distilled from should link atoms to the samples they abstract

## Answer

The relation `distilled_from` should link an atom to the sample or samples it abstracts so the atom’s evidentiary basis remains inspectable. It does not say the atom is identical to any one sample; it marks bounded synthesis, implying that multiple fragments can jointly ground one claim.
