# Atomic Fact (C x D x V)

## Answer

Concept, Dimension, Value triple as the minimum operable unit. Example: (lechuga, parte_comestible, hoja). Concept acts as row, Dimension/Value as column, and the intersection marks a bit (1 or 0) in the boolean matrix. This tripartition enables building orthogonal axes in the logical space and populating matrices from verbal assertions.
