# The meaning layer is directly usable via eval

## Answer

The s-expression layer is a first-class user surface: 'knowledge eval <sexpr>' executes Meaning directly for power users, scripts, and agents. Surface and eval are equivalent by construction; surface is only sugar over the same expressions.
