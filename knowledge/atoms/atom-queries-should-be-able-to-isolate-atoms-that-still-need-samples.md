# Queries should be able to isolate atoms that still need samples

## Answer

Queries should be able to isolate atoms that still need sample links so provenance backfill can be planned instead of forgotten. This is not just topical retrieval; making missing evidence visible implies governance can prioritize the highest-risk gaps as explicit workflow.
