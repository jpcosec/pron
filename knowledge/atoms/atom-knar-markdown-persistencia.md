# Markdown estructurado persiste el conocimiento semántico

## Answer

El conocimiento se persiste principalmente como Markdown estructurado y puede proyectarse a modelos Pydantic u otros tipos. La representación editable y las representaciones tipadas expresan el mismo modelo semántico, sin convertir un formato de ejecución en la fuente primaria.
