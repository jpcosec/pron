# Los agentes deben ser mayoritariamente datos declarativos

## Answer

Un nodo puede declararse casi enteramente mediante datos: id, self, inputs, outputs, knowledge, capabilities, runtime, state-machine y completion-tests. El comportamiento del agente se describe en esa definición componible, en vez de exigir una implementación particular completa para cada agente.
