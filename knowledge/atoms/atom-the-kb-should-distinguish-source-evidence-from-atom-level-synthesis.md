# The KB should distinguish source evidence from atom-level synthesis

## Answer

The KB should distinguish source evidence from atom-level synthesis because an atom is a distilled claim, not a verbatim source fragment. Keeping those layers separate implies reviewers can inspect both the supporting materials and the interpretive step that turned them into a reusable answer.
