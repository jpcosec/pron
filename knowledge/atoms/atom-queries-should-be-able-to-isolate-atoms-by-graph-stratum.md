# Queries should be able to isolate atoms by graph stratum

## Answer

Queries should be able to isolate atoms by graph stratum. Graph stratum is distinct from topic because it separates different layers of the KB, such as provenance, conceptual, and structural relations. That separation makes review, maintenance, and composition more precise by preventing unlike graph elements from being mixed by default.
