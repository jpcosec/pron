# The KB should avoid fake retroactive samples with no recoverable evidence path

## Answer

The KB should refuse retroactive samples when no recoverable evidence path exists. A reconstructed example is not the same thing as a source-bound sample unless the source can still be traced and reopened. Preserving that distinction prevents false precision and keeps provenance gaps visible instead of fabricated away.
