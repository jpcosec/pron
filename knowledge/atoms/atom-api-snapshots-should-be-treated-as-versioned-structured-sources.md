# API snapshots should be treated as versioned structured sources

## Answer

API snapshots should be treated as versioned structured sources. They should bind claims to exact retrieved payloads rather than to unstable live endpoints that can change underneath the same URL. That implies KB support remains reproducible and reviewable across time.
