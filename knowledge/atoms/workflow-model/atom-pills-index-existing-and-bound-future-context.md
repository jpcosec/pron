# Pills index existing and bound future context

## Answer

Pills serve two roles: they point agents to existing atoms, code, docs, or specs that matter for a task, and they carry bounded context for work whose governing knowledge is still being discovered, tested, or implemented. The same pill may be rebound across many tasks when that context is reusable. That in-flight knowledge belongs in pills during execution and should graduate into atoms once it becomes durable project ruling.
