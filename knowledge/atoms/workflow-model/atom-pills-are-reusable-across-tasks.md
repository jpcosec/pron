# Pills are reusable across tasks

## Answer

A pill is not a task instance. It is a reusable atomic execution truth: a guardrail, pattern, decision, model, or index surface that may apply to many tasks across one or more phases. Tasks bind pills opportunistically when the pill's `when`, `where`, or `how_not` matches the work. If a context note cannot be reused beyond one narrow task, it should usually live in the task doc, be generalized into a reusable pill, or graduate directly into atoms instead of remaining as a one-off pill.
