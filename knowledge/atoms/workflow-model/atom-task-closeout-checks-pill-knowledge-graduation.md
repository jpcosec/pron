# Task closeout checks pill knowledge graduation

## Answer

When a task reaches closeout, bound pills should be reviewed for durable residue. If one or more pills were bound and that residue has become durable project knowledge, the task should carry at least one atom reference in `references` before the pill context disappears. Tasks with no bound pills pass this check trivially, and the graduation check remains an affirmable closeout item rather than a hard heuristic gate.
