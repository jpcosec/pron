# Phase closeout reconciles pills and next work

## Answer

When every task in a phase has closed, the workflow must run a phase closeout pass: execute shared integration or end-to-end validation, fix interaction regressions, reconcile pills as stale, redundant, durable, or still-active context, promote durable residue into atoms and materializations as needed, and capture any newly discovered tasks before the next phase starts.
