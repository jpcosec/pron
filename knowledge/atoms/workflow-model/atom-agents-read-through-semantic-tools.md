# Agents read through semantic tools

## Answer

Agents should read modeled project knowledge through SLDB, deskops, spec2viz, or equivalent semantic wrappers so they preserve document type, fields, semantic tags, sections, store identity, and workflow meaning instead of flattening everything into raw text.
