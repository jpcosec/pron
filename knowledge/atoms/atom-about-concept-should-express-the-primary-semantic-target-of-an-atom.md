# About concept should express the primary semantic target of an atom

## Answer

The relation `about_concept` should express the primary semantic target of an atom. It should name the concept the atom is centrally about, rather than leave tags or taxonomy placement to carry that meaning indirectly. That implies concept-level navigation and grouping can rely on an explicit semantic center.
