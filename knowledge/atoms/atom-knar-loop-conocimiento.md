# La ejecución cierra un ciclo de transformación del conocimiento

## Answer

El patrón fundamental proyecta conocimiento hacia un nodo, lo ejecuta mediante un runtime y obtiene un artefacto tipado. Tras validarse, el resultado se incorpora al grafo, cerrando el ciclo de transformación del conocimiento.
