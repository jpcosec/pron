# Semantic errors answer symbol, motive, and next action

## Answer

Every semantic error states three things: which symbol failed, what motive it has (or that it has none), and what the user can do next (nearest candidates for missing nouns, anchor-declaration hint for unknown operations). Never a stacktrace, never a bare 'unknown flag'.
