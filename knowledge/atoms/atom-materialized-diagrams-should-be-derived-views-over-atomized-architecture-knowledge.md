# Materialized diagrams should be derived views over atomized architecture knowledge

## Answer

Materialized diagrams should be derived views over atomized architecture knowledge so visual summaries stay synchronized with the underlying claims. The diagram is not the durable source of truth; treating it as a projection implies it can be regenerated whenever the architecture model changes.
