# Clojure linting keeps the canonical core explicit

## Answer

Clojure linting keeps the canonical core explicit, typed, modular, and free of accidental complexity by enforcing strong naming, small modules, explicit invariants, and disciplined graph or AST boundaries, preventing ad hoc feature accretion inside the core data model.
