# Knowledge set metadata should support post-creation enrichment without reopening the atom text

## Answer

`knowledge set-metadata` should support post-creation enrichment without reopening the atom text because provenance wording, scope, role, and grounding often become clearer after the answer itself is drafted. A dedicated metadata command lets authors refine governance metadata incrementally while keeping the atom body focused on the reusable claim.
