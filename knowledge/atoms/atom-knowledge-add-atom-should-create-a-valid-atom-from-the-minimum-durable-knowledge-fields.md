# Knowledge add atom should create a valid atom from the minimum durable knowledge fields

## Answer

`knowledge add atom` should create a valid atom from the minimum durable knowledge fields: title, 5WH1+ question, answer, and semantic tags, with a stable id generated from the title unless explicitly overridden. This keeps atom creation low-friction while still enforcing the core atomic contract instead of allowing arbitrary note-shaped documents.
