# Atom answers should remain stable enough to be recomposed across future KB layers

## Answer

Atom answers should remain stable enough to be recomposed across future KB layers because compositional reuse depends on bounded knowledge units that do not need to be rewritten every time provenance, structure, or graph support improves.
