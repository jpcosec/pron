# El workflow es una representación de ejecución derivada

## Answer

El workflow representa una ejecución construida a partir de capacidades, nodos y contratos del grafo semántico. El grafo conserva el significado de las piezas, mientras el execution graph organiza su participación para satisfacer un objetivo.
