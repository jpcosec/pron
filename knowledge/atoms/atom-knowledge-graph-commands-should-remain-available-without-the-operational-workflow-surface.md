# Knowledge graph commands should remain available without the operational workflow surface

## Answer

Knowledge graph commands should remain available without the operational workflow surface so graph build, inspection, tracing, and missing-reference checks can be used as knowledge infrastructure rather than as task workflow features. This keeps graph operations attached to the KB layer even when the operational layer is absent or intentionally ignored.
