# Code linting is architectural cleanliness, not only formatting

## Answer

Code linting is the clean-code dimension that keeps code readable, constrained, low-clutter, and structurally aligned with the intended architecture. It covers naming, duplication control, and surface clarity, not only formatter output, preventing accidental complexity from reappearing between core, projections, infrastructure, and surfaces.
