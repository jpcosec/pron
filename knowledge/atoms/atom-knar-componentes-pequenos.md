# Las aplicaciones se componen de nodos pequeños y especializados

## Answer

El sistema descompone las aplicaciones complejas en nodos especializados para que cada transformación pueda comprenderse, probarse y reutilizarse por separado. La complejidad de una aplicación se expresa mediante composición entre piezas y no exige concentrarla en un nodo grande.
