# Source adapters should expose enough structure to support future graph derivation

## Answer

Source adapters should expose enough structure to support future graph derivation because raw ingestion alone is too lossy for provenance, coverage, and relationship extraction workflows. The adapter is not just a transport shim; preserving source structure now implies richer graph construction can happen later without re-harvesting everything.
