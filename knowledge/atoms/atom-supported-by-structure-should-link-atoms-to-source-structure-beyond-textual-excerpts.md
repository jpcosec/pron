# Supported by structure should link atoms to source structure beyond textual excerpts

## Answer

The relation `supported_by_structure` should link atoms to relevant sections, symbols, AST nodes, or layout regions when those structures provide meaningful support beyond a plain textual excerpt. It marks structural evidence rather than mere mention, implying that some claims are justified by source shape as well as quoted text.
