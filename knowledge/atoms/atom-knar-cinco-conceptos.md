# La arquitectura se organiza alrededor de cinco conceptos fundamentales

## Answer

Knowledge es conocimiento semántico persistido; Node promete una transformación; Port expresa el contrato tipado; Runtime materializa la transformación; Projection es una representación particular del conocimiento. Estados, capacidades, tests, permisos, provenance y orquestación complementan ese núcleo.
