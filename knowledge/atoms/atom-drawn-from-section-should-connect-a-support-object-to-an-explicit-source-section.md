# Drawn from section should connect a support object to an explicit source section

## Answer

The relation `drawn_from_section` should connect a sample or structural support object to an explicit source section when section structure is part of the evidence path. It is narrower than a generic source link, implying that section boundaries themselves help explain or recover the support.
