# Atom metadata should live outside atoms in a dedicated registry

## Answer

Atom metadata should live outside atoms in a dedicated registry when it describes the atom rather than the knowledge claim itself. Provenance state, project context, source surface, grounding, and editorial role belong to a parallel metadata layer so the atom can remain a pure knowledge unit.
