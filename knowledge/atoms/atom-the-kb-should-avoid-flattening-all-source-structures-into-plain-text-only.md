# The KB should avoid flattening all source structures into plain text only

## Answer

The KB should avoid flattening all source structures into plain text only. Plain text can preserve content, but it discards structural affordances needed for strong anchoring, support modeling, and coverage analysis. That implies the KB should retain source structure where structure carries meaning.
